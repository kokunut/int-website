# 04. 용어집

## 학생회
| 용어 | 뜻 |
| --- | --- |
| 인트(int) | 인공지능융합대학 학생회 이름 |
| 인융대 | 인공지능융합대학 |
| 집행부 | 학생회 운영진 |
| 정후보 / 부후보 | 선거 당시 회장 / 부회장 후보 (당선 후 회장 / 부회장) |
| 선본장 / 부선본장 | 선거운동본부장 / 부본부장 |
| 검정비 페이백 | 자격증 응시료 일부를 학생회 예산으로 돌려주는 사업 |
| 병역 길라잡이 | 병역 관련 안내 노션 페이지(옛 이름: 군입대 백서) |
| 인융 인터뷰 아카이브 | 인융 인터뷰를 모은 노션 페이지(옛 이름: 공모전 정보) |

## 집행부 부서 (2026, `src/content/council.ts`)
| 부서 | 하는 일 |
| --- | --- |
| 회장단 | 학생회 운영 총괄 (회장·부회장·선본장·부선본장) |
| 홍보부 | SNS·웹사이트 운영, 디자인 |

| 사무부 | 회의록·회계·서류 관리 |

가정: 명단 사진의 정후보/부후보를 회장/부회장으로 표기, 굵은 이름을 부장으로 해석. 사진 총원 표기(26명)와 실제 명단(25명)이 달라 명단 기준으로 반영. 부서 설명 문구는 임의 작성 → 학생회 확인 필요.

## 기술
| 용어 | 뜻 |
| --- | --- |
| ISR | Incremental Static Regeneration. 정해진 주기(10분)마다 페이지를 다시 생성 |
| 목 데이터 | 실제 연동 전 쓰는 예시 데이터 (`src/content`) |
| 폴백 | 외부 데이터 실패 시 대신 쓰는 값 |
