# 04. 용어집

## 학생회
| 용어 | 뜻 |
| --- | --- |
| 인트(int) | 인공지능융합대학 학생회 이름 |
| 인융대 | 인공지능융합대학 |
| 집행부 | 학생회 운영진 |
| 정후보 / 부후보 | 선거 당시 회장 / 부회장 후보 (당선 후 회장 / 부회장) |
| 선본장 / 부선본장 | 선거운동본부장 / 부본부장 |
| 검정비 페이백 | 자격증 응시료 일부를 학생회 예산으로 돌려주는 사업 |
| 군입대 백서 | 군 입대 관련 안내 노션 페이지 |

## 학과 약어 (집행부 명단 표기)
가정: 약어 → 정식 명칭은 학생회 확인 필요. 확정되면 "확인" 열을 갱신.

| 약어 | 정식 명칭(추정) | 확인 |
| --- | --- | --- |
| 반시공 | 반도체시스템공학과 | 미확인 |
| 컴공 | 컴퓨터공학과 | 미확인 |
| 디이노 | 디자인이노베이션전공 | 미확인 |
| 만애텍 | 만화애니메이션텍전공 | 미확인 |
| 정보보호 | 정보보호학과 | 미확인 |
| 양지정 | 양자지능정보학과 | 미확인 |
| 첨단융합 | 첨단융합(계열) | 미확인 |
| 지능기전 | 지능기전공학부 | 미확인 |
| it계열 | IT계열(자유전공) | 미확인 |
| 콘소 | 콘텐츠소프트웨어학과 | 미확인 |
| 인데사 | 인공지능데이터사이언스학과 | 미확인 |

## 기술
| 용어 | 뜻 |
| --- | --- |
| ISR | Incremental Static Regeneration. 정해진 주기(10분)마다 페이지를 다시 생성 |
| 목 데이터 | 실제 연동 전 쓰는 예시 데이터 (`src/content`) |
| 폴백 | 외부 데이터 실패 시 대신 쓰는 값 |
