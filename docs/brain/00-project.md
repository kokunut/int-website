# 00. 프로젝트 개요

## 무엇을 만드나
세종대학교 인공지능융합대학 학생회 **인트(int)** 웹사이트. 학생들이 공지·일정·공모전·복지 혜택·자료를 한곳에서 확인한다.

## 사용자
- **방문자:** 인공지능융합대학 재학생 (대부분 모바일)
- **운영자:** 학생회 집행부 (비개발자). 임기 1년, 매년 교체

## 메뉴
| 메뉴 | 하위 페이지 |
| --- | --- |
| 소개 | 학생회 소개(조직도), 소속 학과(+상세) |
| 소식 | 공지사항(+상세), 캘린더, 공모전(+상세) |
| 복지 | 검정비 페이백, 제휴(+상세), 건의함 |
| 아카이브 | 취업 아카이브(`/archive/career`), 병영 길라잡이(`/archive/military`, 군입대 백서 노션 링크 카드 포함) — 노션 "아카이브" DB |
| 자료실 | 회칙, 회의록, 활동계획서·결산, 서식(+문서 상세) |
| FAQ | 자주 묻는 질문 |

공통: 메인(배너 슬라이드·캘린더·페이백 현황·공모전·공지·노션 바로가기), 푸터(인스타그램·주소), 카카오톡 문의 버튼(FAB)

## 기능 요구사항 (확정)
1. **공지 ↔ 캘린더 연동:** 공지에 행사 기간을 넣으면 캘린더에 자동 표시
2. **캘린더:** 날짜 클릭 → 우측에 그날 일정, 다시 클릭 → 그 달 전체. 분류: 학사일정 / 학생회 행사 / 공모전 마감
3. **팝업:** 노션 팝업 DB(제휴·행사·공지)의 기간 중인 행 + 학생회 주최 공모전(`popup: true`, 접수 기간 중)을 한 팝업창에 합쳐 표시(이전/다음). 보지 않기는 열린 묶음 전체에 적용(ADR-013·014). "오늘 하루 보지 않기", "일주일간 보지 않기"
4. **검정비 페이백:** 예산 소진율만 공개(총예산 50만 원). 개인정보 노출 금지
5. **로그인 없음**
6. **비개발자 운영:** 다음 집행부가 코드를 몰라도 내용 수정 가능 (노션·구글 시트·구글 캘린더)

## 제약
- 비용 0원 (Vercel Hobby, 노션·구글 무료 API)
- 운영 기간 1년 이상, 유지보수 인력 없음 → 단순한 구조 우선
- 색상·로고 미정 → `:root` CSS 변수만 바꾸면 반영되게
